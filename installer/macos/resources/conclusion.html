MediaLake is installed

MediaLake runs in the menu bar. On first start a welcome window lets you set up search (an optional global shortcut and the model to download) and syncing of folders. You can skip both and come back to them later: the search window offers the setup while it is missing.

macOS asks for permission the first time MediaLake reads Desktop, Documents, Downloads or an external drive. You can change this later in System Settings > Privacy & Security > Files and Folders.

Synced folders are mounted while MediaLake runs. If you quit it, they disappear from ~/MediaLake until you start it again; files you changed while offline are sent the next time.

To uninstall, use Settings > General > Uninstall inside MediaLake. It unmounts your synced folders first and asks whether to keep the files you downloaded.
