MediaLake is installed

MediaLake runs in the menu bar. On first start it asks for a global shortcut (default ⌥Space), whether to start at login, and which model quality to download.

macOS asks for permission the first time MediaLake reads Desktop, Documents, Downloads or an external drive. You can change this later in System Settings > Privacy & Security > Files and Folders.

To uninstall, use Settings > General > Uninstall inside MediaLake.
